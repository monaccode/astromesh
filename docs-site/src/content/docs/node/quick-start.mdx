This guide gets Astromesh Node installed and running on your system. Pick your platform and follow the steps.

## Step 1: Install

import { Tabs, TabItem } from '@astrojs/starlight/components';

Node releases are published on GitHub under `node-v*` tags (the repository's "latest" release is the core, so `releases/latest/download/...` URLs do not find the Node packages). Set `VERSION` to the Node release you want:

<Tabs>
<TabItem label="Debian / Ubuntu">

```bash
VERSION=0.1.7
curl -LO https://github.com/monaccode/astromesh/releases/download/node-v${VERSION}/astromesh-node_${VERSION}_amd64.deb
sudo apt install ./astromesh-node_${VERSION}_amd64.deb
```

</TabItem>
<TabItem label="RHEL / Fedora">

```bash
VERSION=0.1.7
curl -LO https://github.com/monaccode/astromesh/releases/download/node-v${VERSION}/astromesh-node-${VERSION}-1.x86_64.rpm
sudo dnf install ./astromesh-node-${VERSION}-1.x86_64.rpm
```

</TabItem>
<TabItem label="macOS">

```bash
VERSION=0.1.7
curl -LO https://github.com/monaccode/astromesh/releases/download/node-v${VERSION}/astromesh-node-${VERSION}-macos.tar.gz
mkdir astromesh-node && tar -xzf astromesh-node-${VERSION}-macos.tar.gz -C astromesh-node
cd astromesh-node
sudo ./install.sh
```

</TabItem>
<TabItem label="Windows">

```powershell
$Version = "0.1.7"
Invoke-WebRequest -Uri "https://github.com/monaccode/astromesh/releases/download/node-v$Version/astromesh-node-$Version-windows.zip" -OutFile astromesh-node.zip
Expand-Archive -Path astromesh-node.zip -DestinationPath astromesh-node

# Run the installer (as Administrator)
cd astromesh-node
.\install.ps1
```

</TabItem>
</Tabs>

Verify the installation:

```bash
astromeshctl version
```

Expected output:

```
astromesh-cli 0.3.1
astromesh core 0.59.0
```

## Step 2: Initialize

Run the interactive configuration wizard. Run as root, it writes `/etc/astromesh/runtime.yaml` and `providers.yaml` (on macOS and Windows the daemon reads a different directory — follow the [macOS](/astromesh/node/installation/macos/#configure) or [Windows](/astromesh/node/installation/windows/#configure) guide for this step):

```bash
sudo astromeshctl init
```

The wizard asks for a node role (`full`, `gateway`, `worker`, `inference`) and a provider (`ollama`, `openai`, `anthropic`, or `skip`). With Ollama it checks `http://localhost:11434` and writes the config even if Ollama is not running yet; with OpenAI or Anthropic it asks for the API key and stores it in `/etc/astromesh/.env`, which the systemd unit loads.

To accept all defaults (role `full`, provider `ollama`) without prompts:

```bash
sudo astromeshctl init --non-interactive
```

:::caution[Packaged installs: the role profile is not found]
In the packaged builds the wizard looks for its role profiles next to its own source tree, does not find them, prints `Profile not found` and writes an empty `runtime.yaml`. On Debian/RHEL the package ships the profiles in `/etc/astromesh/profiles/`: copy the one for your role over it (`sudo cp /etc/astromesh/profiles/full.yaml /etc/astromesh/runtime.yaml`).
:::

## Step 3: Start the Service

<Tabs>
<TabItem label="Linux (systemd)">

The package already enables the unit; it does not start it.

```bash
sudo systemctl start astromeshd
```

</TabItem>
<TabItem label="macOS (launchd)">

```bash
sudo launchctl load /Library/LaunchDaemons/com.astromesh.daemon.plist
```

</TabItem>
<TabItem label="Windows">

`install.ps1` does not register the service. From the extracted folder, register it with the bundled wrapper, then start it:

```powershell
& "$env:ProgramFiles\Astromesh\venv\Scripts\python.exe" .\astromeshd-service.py --startup auto install
Start-Service astromeshd
```

</TabItem>
</Tabs>


Run a full diagnostics check:

```bash
astromeshctl doctor
```

## Step 5: Run Your First Agent

With the service running, pick an agent from `astromeshctl agents list` and call the API:

```bash
curl -s http://localhost:8000/v1/agents/support-agent/run \
  -H "Content-Type: application/json" \
  -d '{"query": "Hello! What can you do?"}' | jq .answer
```

The response carries `answer`, `steps` and `usage`; see [`POST /v1/agents/{name}/run`](/astromesh/reference/api-endpoints/).
