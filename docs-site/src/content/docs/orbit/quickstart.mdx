Get from zero to a production Astromesh stack on GCP in under 10 minutes.

**Prerequisites:**
- Python 3.12+
- [Terraform](https://developer.hashicorp.com/terraform/install) installed and on `PATH`
- A GCP project with billing enabled
- `gcloud` CLI authenticated (`gcloud auth login`)

<Steps>

1. ## Install Orbit

   Install `astromesh-orbit` with the GCP provider extra, next to `astromesh-cli` (which provides `astromeshctl`; Orbit plugs into it):

   ```bash
   pip install astromesh-cli "astromesh-orbit[gcp]"
   ```

   Verify the installation:

   ```bash
   astromeshctl orbit --help
   ```

   ```
   Usage: astromeshctl orbit [OPTIONS] COMMAND [ARGS]...

   Cloud-native deployment for Astromesh.

   Commands:
     init     Interactive setup — generates orbit.yaml.
     plan     Preview infrastructure changes.
     apply    Deploy infrastructure to the cloud.
     status   Show deployment status.
     logs     Read the runtime service's logs from Cloud Logging.
     destroy  Destroy all provisioned infrastructure.
     eject    Export standalone Terraform files.
     upgrade  Re-render Terraform templates (after an Orbit package update) and show what changes.
   ```

2. ## Initialize Configuration

   Run the interactive wizard to generate your `orbit.yaml`:

   ```bash
   astromeshctl orbit init
   ```

   The wizard asks for the project, region, deployment name, environment and preset (`starter` ~$15/mo or `pro` ~$80/mo), then writes `orbit.yaml` and adds `.orbit/` to `.gitignore`.

   <Aside type="caution">
     Pick `staging` or `production` as the environment, or edit a `dev` answer to `develop` afterwards: the schema accepts `develop`, not `dev`.
   </Aside>

3. ## Preview Changes

   Run `orbit plan` to validate your configuration and preview what Terraform will create:

   ```bash
   astromeshctl orbit plan
   ```

   Orbit checks your credentials, the project and the required APIs, creates the Terraform state bucket if needed, renders `.orbit/generated/` and runs `terraform plan`:

   ```
     Orbit Deployment Plan

     Validating... OK
     OK State bucket created: gs://my-project-123-astromesh-orbit-state

     Resources to create: 19
     Resources to update: 0
     Resources to destroy: 0
   ```

   <Aside type="tip">
     If a required GCP API is not enabled, validation fails and prints the `gcloud services enable` command to run. See [GCP Provider](/astromesh/orbit/gcp-provider/#required-gcp-apis) for the full list.
   </Aside>

4. ## Deploy

   Apply the plan to provision your stack:

   ```bash
   astromeshctl orbit apply
   ```

   `apply` does not prompt — it runs `terraform apply -auto-approve` — so review the plan first. When it finishes it prints the runtime URL and writes `.orbit/orbit.env` with the Terraform outputs.

5. ## Verify

   Check the status of your deployment:

   ```bash
   astromeshctl orbit status
   ```

   It lists the `astromesh-runtime` Cloud Run service with its status and URL, and the state bucket.

   Test the runtime health endpoint:

   ```bash
   curl https://astromesh-runtime-abc123.run.app/v1/health
   ```

   ```json
   {"status": "ok", "version": "0.59.0"}
   ```

6. ## Clean Up (optional)

   When you are done, tear down everything:

   ```bash
   astromeshctl orbit destroy
   ```

   <Aside type="note">
     The state bucket is not deleted by `orbit destroy` — it contains the record of what was destroyed. You can remove it manually with `gsutil rm -r gs://my-project-123-astromesh-orbit-state` after confirming everything is torn down.
   </Aside>

</Steps>
